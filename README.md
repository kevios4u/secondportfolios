# Kevin Nkwe Portfolio

A responsive personal portfolio built with HTML, CSS, JavaScript, and a small PHP contact handler.

## Pages

- `index.html` - main portfolio landing page
- `pages/about.html` - extended profile
- `pages/projects.html` - project listing
- `pages/login.html` - login form demo

Open `index.html` directly in a browser for the static site. Use a PHP-capable server if you want to test `contact.php`.
